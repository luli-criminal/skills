# skills

个人收集的 WorkBuddy / Agent Skills。每个技能是一个独立目录，内含一份 `SKILL.md`（YAML frontmatter + 正文说明）。

## 技能列表

| 技能 | 用途 |
|---|---|
| [`PersonGPT`](PersonGPT/SKILL.md) | 用公开渠道溯源具体人物的学历、毕业院校、毕业时间、就业去向、任职轨迹。核心是先锁定唯一身份、再穷尽定向检索，最后诚实区分「查不到」与「不存在」 |

## 目录结构

```
.
├── README.md
└── PersonGPT/
    └── SKILL.md
```

## 安装方式

把技能目录复制到本地技能目录即可：

```bash
# 用户级（对所有项目生效）
cp -r PersonGPT ~/.workbuddy/skills/

# 项目级（仅对当前工作区生效）
cp -r PersonGPT <project>/.workbuddy/skills/
```

## 免责声明

本仓库收录的技能只描述**公开信息的检索方法与判断规则**，不含任何具体个人的隐私信息。

技能正文中出现的机构名、政策文号、奖项名称（如行业奖项、主管部门规章），仅为说明检索入口之用，均为公开信息。若将相关方法用于背调、招聘核实等正式用途，请注意：公开检索只能定性、不能定论，正式结论须以对方提供的学历/学位/任职证明或官方渠道为准。
